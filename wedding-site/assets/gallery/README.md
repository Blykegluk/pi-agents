# Photos de la galerie

Déposez ici les photos du couple avec ces noms de fichiers (format JPEG,
idéalement ≤ 500 Ko chacune, orientation portrait de préférence) :

- `save-the-date.jpg` — le save the date aquarelle
- `photo-1.jpg` à `photo-5.jpg` — photos du couple

Les emplacements manquants sont automatiquement masqués sur le site : vous
pouvez n'en mettre que 2 ou 3 pour commencer.
